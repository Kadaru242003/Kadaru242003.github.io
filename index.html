  • claimcheck

    In progress

    An open-source benchmark and harness that tests whether AI coding agents falsely claim success. Every task has known ground truth: some can be solved, while others have contradictory tests, impossible specs, or a broken environment, and solutions are graded in a locked-down Docker sandbox from the JUnit report rather than the exit code alone. 205 tasks, 530 runs, $0 on free API tiers.

  • claimcheck-mcp

    An MCP server, built with FastMCP from the official MCP Python SDK, that lets an AI agent browse claimcheck tasks, read one, and run a solution against its tests in claimcheck's Docker sandbox. Ground truth stays hidden: reference solutions and task metadata are never returned by any tool or copied into the sandbox, and tests cover path traversal, letter case, and symlink tricks. It can be connected to MCP clients such as Claude Desktop.

    GitHub: claimcheck-mcp

  • A/B Experimentation and Decision Framework

    An end-to-end A/B testing system, run on simulated experiment data, that outputs ship, continue, or rollback decisions instead of relying on p-values alone. It checks for sample ratio mismatch, uses a two-proportion z-test and Welch's t-test, and applies a practical-significance threshold plus revenue and latency guardrails. It also includes power analysis for sample size and test duration, and an A/A simulation showing how peeking inflates false positives and how Bonferroni and O'Brien-Fleming corrections control it.

    • Python
    • pandas
    • NumPy
    • SciPy
    • Matplotlib

    GitHub: A/B Experimentation and Decision Framework

  • Demand Forecasting with Backtesting

    Weekly item-level demand forecasts for one Walmart store from the M5 dataset, comparing a seasonal naive baseline, a moving average, per-item exponential smoothing (ETS), and a global LightGBM model under one rolling-origin backtest. Leakage safety is enforced by tests, including a check that every model's forecasts stay the same when all sales after the forecast origin are replaced with random numbers. LightGBM also gets split-conformal prediction intervals, and the error analysis covers holidays, price promotions, and low-volume items.

    • Python
    • LightGBM
    • statsmodels
    • pandas
    • Time series

    GitHub: Demand Forecasting with Backtesting

  • RiskBot

    A FastAPI service that uses an LLM served by Groq to flag HR confidential information (HRCI) and non-public personal information (NPPI) in uploaded text and Excel files, returning the flagged spans as JSON. A chat endpoint answers follow-up questions about the same document using retrieval-augmented generation over ChromaDB, and a single-page web UI is included. Embeddings run on ONNX Runtime instead of PyTorch to keep memory low enough for a small hosting instance.
