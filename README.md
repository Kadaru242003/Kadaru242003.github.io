# kadaru242003.github.io

Personal portfolio of Harshith Kadaru, served at https://kadaru242003.github.io.

Plain HTML, CSS, and a small script. No framework. A short Python build step (standard library only) assembles `_site/` and adds the GitHub activity graph.

## Files

| File | Purpose |
|---|---|
| `index.html` | Home page: Experience, Projects, GitHub Activity (added at build time), Achievements, Education, Skills, Contact |
| `projects/*.html` | One detail page per project, with a visual at the top. Generated by `scripts/dev/gen_projects.py` and committed |
| `styles.css` | Design tokens (type, color, spacing), light and dark themes, layout |
| `script.js` | Theme toggle, screenshot lightbox, fade-in on scroll, current-section highlight. All optional: the site works without JavaScript |
| `assets/fonts/` | Self-hosted Fraunces and Inter (WOFF2) with their SIL Open Font License files |
| `assets/projects/` | Project figures copied from the project repos. `*.png` are the sources, `*.webp` are served |
| `assets/` | Headshot, GW photo, and RiskBot screenshots. `*.png` files are sources and are not deployed |
| `scripts/fetch_contributions.py` | Fetches the GitHub contributions calendar over GraphQL with the workflow token |
| `scripts/build.py` | Copies the site into `_site/` and inlines the contributions graph as static SVG |
| `404.html`, `favicon.svg`, `og-image.png`, `robots.txt`, `sitemap.xml`, `resume.pdf` | Supporting files |
| `docs/screenshots/` | Full-page screenshots for pull requests (not deployed) |
| `lychee.toml`, `.htmlvalidate.json` | Link checker and HTML validator settings |
| `.github/workflows/site.yml` | Checks, build, and deployment |

## Checks and deployment

`.github/workflows/site.yml` runs on every pull request, every push to `main`, and weekly:

- **HTML validity**: html-validate and the W3C Nu HTML Checker on the source pages and on the built `_site/`, plus a check that no file contains an em dash.
- **Broken links**: lychee checks every link. LinkedIn is skipped because it blocks automated requests.
- **Build**: fetches the contributions calendar and builds `_site/`. If the fetch fails, the site builds without the GitHub Activity section.

On a push to `main`, a manual run, or the weekly schedule, if the checks pass, `_site/` is deployed to GitHub Pages. The weekly run keeps the contributions graph current.

## Preview locally

```bash
python3 scripts/build.py          # without the GitHub graph (no token locally)
cd _site && python3 -m http.server 8000
# open http://localhost:8000
```

To change a project page, edit `scripts/dev/gen_projects.py` and run `PYTHONPATH=scripts/dev python3 scripts/dev/gen_projects.py .`
